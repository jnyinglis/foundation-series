# Foundation

An Elite-style interplanetary exploration game set in the worlds of Isaac Asimov's
*Foundation* series. It runs in the browser as a single static page. All planets,
suns, nebulae and star fields are generated by shaders, so there are no asset files
to download.

A non-commercial fan project. It is based on the books, not on any screen adaptation.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # static site in dist/
```

The `dist/` folder can be hosted on GitHub Pages or any static host.

## Two experiences

- **Explore.** Free flight. Every world is open. Fuel is the only limit.
- **Story: The Second Mind.** You are R. Taren Vesk, a robot built in secret under
  Giskard Reventlov's guidance and released into the Galaxy by R. Daneel Olivaw
  with its origin memory blocked. An Encyclopedist named Ilen Sarvo has found the
  one surviving index entry for a world called Earth. Someone has erased every
  other copy for ten thousand years. Chapters unlock worlds as the story moves.
  Chapters one to five are written, and chapter six opens at Aurora.

Stories are data. See `src/story/types.ts` for the format and
`src/story/second-mind.ts` for the script. A scene fires on a trigger (start,
arrive, orbit, depart, flag) and runs steps: dialogue, choices, flags, objectives,
journal entries, unlocked worlds, crew, chapter cards, strain, credits and fuel.

## Controls

| Key | Action |
| --- | --- |
| Click | Capture the mouse and fly |
| Mouse / Arrows | Pitch and yaw |
| Q E or A D | Roll |
| W S | Throttle up / down |
| Shift | Boost |
| X | Cut throttle |
| M | Galaxy map |
| J | Jump to the selected system |
| I | World information |
| K | Journal (story mode) |
| L | Land, or return to orbit (Trantor, Radole) |
| V | Voice on or off |
| Space, 1-3 | Advance dialogue, choose |
| H | Controls panel |
| Esc | Release the mouse / close panels |

Fly close to a planet to enter orbit. Orbit refuels the ship.
The jump range is limited. Select a far star and the chart plots a chain of
jumps; each J takes the next hop.

## Worlds

37 named systems from the books, plus four unnamed catalogue stars that link
the regions, placed on a plausible galactic map:

- **Galactic Core:** Trantor, Helicon, Synnax, Neotrantor
- **The Periphery and the Four Kingdoms:** Terminus, Anacreon, Smyrno, Konom, Daribow, Askone, Korell, Siwenna, Glyptal IV, Nishaya
- **Imperial Frontier and Provinces:** Horleggor, Arcturus, Cinna, Iwernia
- **Independent Traders:** Haven, Iss, Mnemon, Radole
- **The Mule:** Kalgan, Tazenda, Rossem
- **Imperial Provinces:** Santanni, Sark, Florina
- **Search for Earth:** Sayshell, Gaia, Comporellon, Aurora, Solaria, Melpomenia, Alpha, Earth, Vega

Each world has a type (terrestrial, lush, ocean, desert, ice, barren, or metal for
Trantor), a seed, a star, and a short lore entry. See `src/data/worlds.ts`.

## Places

Press L in orbit to land where a site is charted. Siwenna opens the dark Imperial
archive. Trantor opens an atmospheric
flight over the world-city: tens of thousands of instanced towers, lit windows,
traffic lanes and fog, all procedural, with the Galactic Library dome and its
beacon as a landmark to fly to. The story then moves into the Library rotunda
and the Sacratorium of Mycogen. Radole opens the Twilight City cantina, a
walkable interior with stylised characters built from primitives. In the story,
chapter two moves into the cantina for the meeting with Corin. Characters turn
to the speaker, gesture, and move their mouths to the voice clip. A glTF avatar
can replace a procedural figure later through the same `Figure` interface.

## Blender scenes

Interiors are built by script in Blender, run headless, with the lighting baked
into texture atlases. The game draws the baked meshes unlit, so a room with
soft shadows and bounced light costs almost nothing at runtime. Emissive props
such as lamps and bottles stay live so they bloom.

```bash
brew install --cask blender     # once
npm run scene:cantina           # builds public/scenes/cantina.glb and cantina.json
npm run scene:archive           # the Siwenna archive
npm run scene:library           # the Galactic Library rotunda
npm run scene:sacratorium       # the Sacratorium of Mycogen
npm run scene:terrace           # the Sayshell terrace at dusk
npm run scene:vault             # the Comporellon archive vault
npm run scene:cantina -- --fast # quick low-sample preview
```

Shared helpers live in `blender/common.py`. `blender/cantina.py` lays out the room, assigns procedural node materials,
places area lights and an emissive window, joins the static geometry into a
shell and a furniture mesh, unwraps them, bakes a combined pass per mesh, and
exports glTF. It also writes the collider boxes, spawn point and character
placements that `src/interior.ts` reads. If the scene files are missing, the
game falls back to the procedural room.

## Characters

Named characters are rigged humans built with MPFB, the MakeHuman plugin for
Blender, from a script. Each character is a few lines in
`blender/characters.py`: body sliders, skin, hair, eyebrows, clothes. The
script bakes the body shape, adds one jaw shape key for lip sync, attaches the
Mixamo-named skeleton, dresses the figure so hair and clothes get weights, drops
the helper geometry, shrinks textures, and exports a 2 to 4 MB glTF per
character to `public/characters`.

```bash
# once: install the MPFB extension and the CC0 asset packs
/Applications/Blender.app/Contents/MacOS/Blender --command extension install mpfb --sync --enable
# then unpack makehuman_system_assets, skins, hair, eyebrows, eyelashes, shirts, pants,
# shoes, bodyparts and suits packs into Blender's MPFB user data folder
npm run characters            # builds every character
npm run characters -- corin   # one character
```

In the game, `src/avatar.ts` loads a character and animates it on its skeleton
in code: relaxed arms, a seated pose on stools, breathing, head look-at,
talking gestures, and a mouth driven by the voice clip level through the jaw
shape key. The procedural figure remains the fallback when a file is missing.

## Portraits

Each speaking character has a painted portrait beside the dialogue, generated
once with OpenAI image generation:

```bash
npm run portraits        # writes public/portraits/<key>.webp
```

Prompts and the shared style live in `src/story/voice.ts`.

## Voice

Dialogue lines are spoken. The game plays a generated clip per line when one
exists, and falls back to the browser's own voices when it does not. Press V to
turn voice off or on.

To generate the clips with OpenAI text-to-speech:

```bash
cp .env.example .env     # put your OPENAI_API_KEY in .env
npm run voice            # writes public/voice/<id>.mp3 and a manifest
```

Only new or changed lines are generated. The cast, tone instructions and the
per-character audio processing (Taren's slight chorus, the comms radio filter)
live in `src/story/voice.ts` and `src/audio.ts`. The key stays on your machine.

## Structure

```
index.html             page and HUD markup
src/main.ts            game loop, state, jump sequence, save game
src/system.ts          builds a star system: sun, planet, clouds, atmosphere, rings, moons, sky
src/ship.ts            six-degree-of-freedom flight model
src/galaxy.ts          galaxy map with jump range and selection
src/hud.ts             HUD and panels
src/audio.ts           procedural ambient sound (Web Audio)
src/shaders/           GLSL: noise, planet, clouds, atmosphere, sun, skybox, hyperspace jump
src/data/worlds.ts     the named worlds
src/story/             story format, engine, and scripts
src/dialogue.ts        dialogue panel, portraits and chapter cards
src/city.ts            procedural Trantor flythrough
src/interior.ts        walkable interiors and procedural characters
src/avatar.ts          rigged MakeHuman characters animated in code
blender/               headless Blender scene builders
scripts/connectivity.ts  checks that every world is reachable by jump chains
```

Stack: Three.js, TypeScript, Vite. Save game is kept in `localStorage`.

## Roadmap

1. **Story.** Chapter three onward: Siwenna, Trantor, the Spacer worlds, Earth.
2. **Core loop.** Docking, markets, cargo, missions tied to the Seldon Crises.
3. **AI backend.** An optional server that uses a language model to voice station
   controllers, traders, and encyclopedia entries in the style of the books. The
   game must keep working without it.
4. **Depth.** Combat, factions, Trantor sectors as dockable locations, the Time Vault.
